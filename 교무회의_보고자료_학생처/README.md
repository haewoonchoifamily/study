# 교무회의 보고자료 (학생처) 검토기

한글(.hwp / .hwpx) 보고서를 올리면 텍스트를 자동 추출하고, 줄마다 **삭제**(취소선)·**◆중점**(앞에 ◆)을 체크한 뒤 **확정**하면 표시본/최종본을 볼 수 있는 웹앱입니다. 설치 없이 `index.html` 하나로 동작하며, 파일은 브라우저 안에서만 처리됩니다.

> 「한글 보고서 검토기」(주간업무)를 복제한 교무회의 보고자료용 앱입니다. Worker 이름은 `hwp-review-gyomu`로 별도이며 저장소(Durable Object)도 분리되어 있습니다.

- 제목·소제목·일정 줄(`1. … : …` 형식이 아닌 줄)은 체크 없이 그대로 표시
- 확정 후 ✎ 수정으로 돌아가 다시 체크 가능
- 최종본/표시본 복사(서식 포함)

## 실행
```
npx --yes http-server@14.1.1 교무회의_보고자료_학생처/public -p 8767
```

## 공용 저장 (Cloudflare)
`src/index.js`의 Durable Object가 현재 문서 1건(체크 상태·확정 여부)을 저장하고, 접속한 모든 사람이 4초마다 동기화합니다. 서버에 연결되지 않으면(파일로 직접 열기 등) 이 브라우저에만 저장됩니다.
배포: `npx wrangler deploy` (Workers Builds가 main push 시 자동 실행)

## 한글(.hwp)로 저장
확정 화면의 「한글(.hwp)로 저장」은 업로드한 **원본 .hwp 파일**의 본문을 고쳐서 새 파일로 내려받습니다(서식·표 유지).
삭제한 줄은 문단째 제거하고, 각 소제목(▣ …) 아래 번호를 1번부터 다시 매기며, 중점 줄 앞에 ◆를 넣습니다.
원본 파일은 공용 저장소에 함께 보관되어 다른 사람이 열어도 저장할 수 있습니다(최대 12MB).
