# 한글 보고서 검토기

한글(.hwp / .hwpx) 보고서를 올리면 텍스트를 자동 추출하고, 줄마다 **삭제**(취소선)·**◆중점**(앞에 ◆)을 체크한 뒤 **확정**하면 표시본/최종본을 볼 수 있는 웹앱입니다. 설치 없이 `index.html` 하나로 동작하며, 파일은 브라우저 안에서만 처리됩니다.

- 제목·소제목·일정 줄(`1. … : …` 형식이 아닌 줄)은 체크 없이 그대로 표시
- 확정 후 ✎ 수정으로 돌아가 다시 체크 가능
- 최종본/표시본 복사(서식 포함)

## 실행
```
npx --yes http-server@14.1.1 한글보고서_검토기/public -p 8766
```
