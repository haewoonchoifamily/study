# 📒 AI 오답노트

틀린 문제 사진을 올리면 AI(Claude 또는 Gemini)가 읽고 오답노트를 만들어 주는 웹앱입니다. 설치 없이 `index.html` 파일 하나로 동작합니다.

## 기능
- **과목 폴더 관리**: 폴더 추가·이름 변경·삭제, 노트 폴더 이동
- **사진 → 오답노트**: 클릭 / 드래그 / Ctrl+V 붙여넣기, 여러 장 한 번에
- **노트 화면**: 왼쪽은 문제 이미지, 오른쪽은 📌 핵심 팁 · 🔍 오답 분석 · ✅ 정답과 풀이 · 🧩 관련 개념
- **유사 문제 만들기**: 같은 개념·같은 함정을 숫자와 상황만 바꾼 문제 생성
- **복습 퀴즈**: 간격 반복(맞히면 3→7→14→30→60일, 틀리면 다음 날), 유사 문제로 출제 가능
- 검색, 편집, 인쇄(좌우 2단), 백업 내보내기/불러오기

## 실행
```
npx --yes http-server@14.1.1 오답노트 -p 8765
```
브라우저에서 http://localhost:8765 를 연 뒤 ⚙️ 설정에서 API 키를 입력하세요.

- Gemini: https://aistudio.google.com/apikey (무료 사용량 있음)
- Claude: https://console.anthropic.com/settings/keys (선불 크레딧, 사용량만큼 차감)

API 키와 노트는 브라우저(localStorage/IndexedDB)에만 저장됩니다.
