# 계명대학교 수시모집 경쟁률 조회

유웨이(uway) 실시간 경쟁률 페이지에서 계명대학교 데이터를 읽어와,
**학과를 고르면 그 학과의 전형별 경쟁률**을 표와 그래프로 보여준다.

## 실행

```bash
python kmu_ratio_app.py          # GUI (학과 선택)
```

왼쪽에서 학과를 고르면 오른쪽에 전형별 경쟁률이 나온다.

- **주요학과만** 체크 해제 → 전체 89개 모집단위
- 검색창에 이름 일부 입력 (예: `공학`, `교육`)
- 열 제목 클릭 → 정렬 (모집/지원/경쟁률)
- 탭: `전형별 경쟁률` / `그래프` / `전형별 총괄`
- `새로고침` 으로 최신값, `CSV 저장` 으로 전체 데이터 내보내기

경쟁률 색: 3배 이상 <span style="color:#c0392b">빨강</span> ·
1배 이상 <span style="color:#b9770e">주황</span> · 1배 미만 회색.

### 명령줄로도 쓸 수 있다

```bash
python kmu_ratio.py                      # 주요학과 20개 경쟁률
python kmu_ratio.py 의예과 간호학과        # 특정 학과
python kmu_ratio.py --list --all         # 전체 모집단위 한 줄 요약
python kmu_ratio.py --summary            # 전형별 총괄
python kmu_ratio.py --csv 경쟁률.csv      # 전체 데이터 CSV
python kmu_ratio.py --refresh 의예과      # 캐시 무시하고 새로 받기
```

## 구성

| 파일 | 역할 |
|---|---|
| `kmu_ratio.py` | 수집·파싱·집계 + 명령줄 인터페이스 |
| `kmu_ratio_app.py` | tkinter GUI |
| `.cache/` | 받아온 HTML 캐시 (10분). 지워도 된다 |

필요 패키지: `requests`, `lxml` (+ 그래프용 `matplotlib`, 없어도 표는 동작).

## 데이터 출처

```
목록  https://m.uway.com/power/            대학별 경쟁률 링크
상세  http://ratio.uwayapply.com/<토큰>     계명대 경쟁률 (서버 렌더링 HTML)
```

상세 페이지 주소의 토큰은 모집 연도마다 바뀐다. 그래서 실행할 때마다 목록
페이지에서 계명대학교의 링크를 **자동으로 찾아낸다**(`discover_ratio_url`).
찾지 못하면 `RATIO_URL_FALLBACK` 에 적어둔 주소를 쓴다.

원본은 10분 단위로 갱신되므로 캐시도 10분이다. 네트워크가 끊기면 오래된
캐시라도 사용하고 그 사실을 표시한다.

## 읽을 때 주의할 점

### 1. 모집인원을 여러 줄이 나눠 쓰는 전형이 있다

실기/실적(예체능전형)의 관현악과는 악기별로 줄이 나뉘지만
`모집 13명 / 경쟁률 0.08` 은 **관현악과 전체 값**이라 줄마다 똑같이 적혀 있다.
그대로 더하면 모집인원이 부풀려진다.

그래서 같은 (전형, 모집인원, 경쟁률)인 줄들을 모아, **합쳐야만 그 경쟁률이
설명되고 각 줄 단독으로는 설명되지 않을 때** 하나로 묶는다
(`kmu_ratio.group_rows`). 위 관현악과는 지원 합계 1명 / 13 = 0.08 로 맞고
각 줄(1명, 0명, 0명)로는 맞지 않으므로 묶인다.

반대로 `의예과[경상북도 영주권] 1명/3명/3.00` 과 `[상주권] 1명/3명/3.00` 은
숫자가 같지만 **각각 독립**이다. 합치면 6/1 = 6.00 이 되어 표기된 3.00 과
어긋나고, 각 줄 단독으로는 3/1 = 3.00 으로 맞기 때문에 묶지 않는다.

이 규칙으로 16개 전형 중 14개가 대학 발표 소계와 **정확히 일치**한다.

### 2. 남은 2개 전형은 원본 자체가 맞지 않는다

`실기/실적(예체능전형)` 과 `학생부교과(만학도전형)` 은 어떤 규칙으로도 소계를
재현할 수 없다. 만학도전형은 **학과마다 7명**으로 적혀 있는데 소계는 **70명**이라,
55개 학과분을 어떻게 묶어도 70이 나오지 않는다. 대학이 모집인원을 학과별로
배분해 고시하지 않은 전형이기 때문으로 보인다.

그래서 이런 전형이 섞인 학과에는 화면과 콘솔에 **※ 표시**를 띄운다.

- **각 줄의 전형별 경쟁률은 원본 그대로이며 정확하다.**
- 지원인원은 어떤 전형에서도 소계와 완전히 일치한다 (검증됨).
- 학과 **통합 모집인원/통합 경쟁률**만 참고값으로 볼 것.

정확한 값이 필요하면 `전형별 총괄` 탭(대학 발표 소계 그대로)을 보면 된다.

### 3. 그 밖에

- 경쟁률은 마감 직전에 급변한다. 접수 마감은 2026년 9월 11일(금) 18:00.
- 계명대는 최대 6개 전형까지 복수지원이 가능해, 학과별 지원인원 합계에는
  같은 지원자가 여러 번 들어갈 수 있다.
- `[교직]` 은 교직과정 표시일 뿐 모집단위를 나누는 값이 아니라 학과명에서 뺀다.

## 다른 대학으로 바꾸려면

`kmu_ratio.py` 위쪽의 `UNIVERSITY` 를 바꾸면 된다. 목록 페이지에 있는 대학이면
링크를 자동으로 찾는다. 다른 지역이면 `LIST_URL` 의 `o_loc` 값도 함께 바꾼다
(현재는 대구·경북 `12:11`).
